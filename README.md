# J.A.V.I. Android

Aplicación Android nativa del asistente J.A.V.I.

## Primera versión instalable

- Chat conectado a J.A.V.I. Core.
- Reconocimiento de voz en español.
- Modo beta de escucha de “Javi”.
- Solicitud del rol de asistente de Android.
- Apertura de WhatsApp y YouTube por voz.
- Creación de alarmas.
- Wake-on-LAN para despertar una computadora suspendida.

El APK de prueba se compila automáticamente con GitHub Actions.
